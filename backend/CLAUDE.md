# backend/ — Express API

Scope: everything under `backend/`. See root `AGENTS.md` for the full stack list, environment variables, and API route index — this file only adds backend-local detail not already there.

## Entry points

- `src/server.ts` boots the HTTP server; `src/app.ts` wires middleware and mounts every router from `src/modules/*`.
- Route mounting order in `app.ts` matters for `/api` vs `/public` vs authenticated routes — check it before adding a new top-level path prefix.

## Build/run

- `npm run dev` — `tsx watch`, no build step needed for local iteration.
- `npm run build` — `tsc`; **required check before considering a backend task done** (see AGENTS.md Verification).
- `npm run prisma:migrate` / `npm run prisma:generate` — after any `prisma/schema.prisma` change, run both, then rebuild.
- `dist/` is generated by `tsc` — never hand-edit, never treat as source of truth.

## Directories

- `src/config/` — `env.ts` (Zod-validated env), `prisma.ts` (shared Prisma client singleton).
- `src/middleware/` — `auth.middleware.ts` (bearer JWT → `AuthRequest.user`), `error.middleware.ts` (JSON error shape, mounted last in `app.ts`).
- `src/modules/` — one folder per feature; see [src/modules/CLAUDE.md](src/modules/CLAUDE.md).
- `src/scripts/` — one-off/CLI scripts run via `tsx` (`seed-google-config.ts`, `test-s3-connection.ts`, `test-api-upload.ts`), not part of the request path.
- `src/utils/` — shared pure helpers (e.g. bigint→string JSON conversion, encryption helpers).
- `prisma/schema.prisma` + `prisma/migrations/` — MySQL schema, one directory per migration; never edit an already-applied migration file.

## Local conventions

- New feature = new `src/modules/<feature>/<feature>.routes.ts` (+ `.service.ts` when Google/S3/provider logic is involved) mounted in `app.ts`.
- Every authenticated route uses `requireAuth` and reads `req.user` typed as `AuthRequest`.
- Zod schemas validate request bodies/query params inline in the route file, close to the handler that uses them.
- Route handlers call `next(error)` for anything unexpected; `error.middleware.ts` is the only place that formats the JSON error response.
- `bigint` Prisma fields (file sizes, quotas) must be stringified before `res.json(...)` — Express's JSON serializer throws on raw `bigint`.
